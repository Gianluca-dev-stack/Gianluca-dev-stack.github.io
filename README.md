# Gianluca Sausa — Memoria

I’m a computer science student at UMass Amherst building Memoria, a local-first application for reviewing and approving project notes before AI coding tools reuse them.

## Project overview

[Explore Memoria](https://gianluca-dev-stack.github.io/Memoria/)

Memoria uses TypeScript, Bun, and SQLite, with a local HTTP API, a command-line interface, and Model Context Protocol (MCP) tools. My work includes approval workflows, project-scoped retrieval, context previews, and a Windows desktop preview built with Tauri.

The application lets developers review proposed notes, approve or reject them, and preview the context available to connected tools. Context receipts help check package consistency; they do not prove that a model used the supplied context.

Memoria is in private preview. This repository contains the public project website; the application source is maintained separately in a private repository.
